# Portfolio Boundaries

This is a public professional portfolio, not a copy of any production system.

## What is included

- The business problem and intended operating outcome
- Sanitized, high-level architecture
- General technology categories
- Human review and control patterns
- Lessons that can be applied across finance organizations
- Outcomes that can be supported without revealing confidential information

## What is not included

- Proprietary information or confidential company data
- Production source code or internal repositories
- Prompts, model instructions, classification rules, or scoring logic
- Detection thresholds, calibration values, allowlists, or exception criteria
- Credentials, identifiers, URLs, account details, counterparties, or financial records
- Internal file structures, deployment details, or security configurations
- Company-specific policies, decision rules, or business logic

All examples are synthetic or abstracted. Diagrams omit implementation details deliberately. The material is intended to demonstrate finance-transformation thinking, system design, controls, and measurable operating value without enabling reconstruction of a production implementation.
